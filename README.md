The flow of the website: the user can enter the page where they can add pokemon to the cart in 
test.chesterhuey.com this information sends requests to the database using nodejs and inserts 
information like page clicks and event handling into the mysql database. This information is then 
looked through in my server where it parses the sql databases information to display information 
such as amount of clicks, time spent on the website, and possible insights that could lead to 
further action. There are 3 different kinds of users, admin guest, and superuser that have 
different types of viewing levels that are handled through authentication using sessions and 
cookies. Additionally the passwords are all hashed.
